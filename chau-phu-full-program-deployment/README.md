# Châu Phú 통합 프로그램 배포본

이 폴더는 업로드해 주신 다중 탭 HTML을 웹에 배포하고, 내장된 수위·강우·날씨 화면이 같은 도메인의 API를 통해 자료를 읽도록 구성한 Vercel용 패키지입니다.

## 배포 시 필요한 파일

폴더 안의 `index.html`, `api/`, `lib/`, `vercel.json`, `package.json`을 함께 GitHub 저장소에 올리거나, 이 폴더 자체를 Vercel 프로젝트의 Root Directory로 지정해야 합니다. `index.html`만 Google Drive에 올리면 API 경로가 없어서 실제 자료 연동은 되지 않습니다.

## 자료 연결

- MRC 수위·강우: 기존 Google Sheet의 `MRC_latest`와 `MRC_history` CSV 내보내기 주소를 서버 함수가 읽습니다. 시트는 링크가 있는 사용자가 뷰어로 열 수 있어야 합니다.
- 날씨 예보와 과거 날씨: Open-Meteo API 서버 함수가 같은 사이트 주소에서 제공합니다.
- 지도: Leaflet을 사용하며 OpenStreetMap 표준 타일을 불러옵니다. 파일로 직접 여는 대신 HTTPS 웹 주소로 접속하면 타일 요청에 웹 페이지 출처가 전달됩니다. 지도 표기와 OSM 저작자 표시를 유지하고, 타일을 미리 대량 내려받지 않습니다.
- 염도: 현재 연결된 실시간 Dinh Yen 염도 자료는 없습니다. 기존 화면의 자료 상태를 그대로 표시합니다.

## 최신 자료 표시 방식

앱이 열려 있고 화면이 활성화되어 있을 때 15분마다 시트를 다시 확인합니다. 새 측정값 자체는 원본 시트가 갱신되어야 생깁니다. API 연결에 실패하면 HTML에 포함된 2026-11-10 시점의 과거 캡처값이 fallback으로 표시될 수 있으므로, 화면의 자료 지연/스냅샷 표시를 확인해야 합니다.

## 공개 전 확인

이 페이지와 API를 공개하면, 시트에 있는 MRC 자료도 웹사이트 방문자에게 공개됩니다. 시트의 공유 권한과 포함된 데이터를 확인한 다음 배포하세요. Vercel에서 이 패키지 폴더를 프로젝트 Root Directory로 지정해 Preview 배포 후 확인하는 것을 권장합니다.
